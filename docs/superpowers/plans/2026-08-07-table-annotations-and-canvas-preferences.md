# Table Annotations and Canvas Preferences Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add portable five-color table annotations and memos, a persistent hosted-canvas light/dark toggle, and 70% Control-wheel zoom sensitivity without building an IntelliJ distribution.

**Architecture:** Extend the portable layout model, pass annotation state through flow-node data, and edit it through a selected-node toolbar. Keep theme preference local to the host webview and isolate custom pointer-centered zoom math in a tested renderer helper.

**Tech Stack:** TypeScript, React 19, React Flow 12, Node test runner, CSS custom properties

## Global Constraints

- Store only semantic color tokens and plain-text memos in layout JSON.
- Support exactly `blue`, `green`, `yellow`, `red`, and `purple`, plus reset to default.
- Theme preference is personal and never written to layout JSON.
- Plain trackpad scroll pans; Control-scroll and pinch zoom at sensitivity `0.7`.
- Preserve zoom bounds `0.1` and `2.5`.
- Do not build an IntelliJ plugin ZIP.
- Do not modify or commit the user-provided `image.png`.
